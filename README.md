Bem vindo ao meu projeto pessoal de gerenciamento de demandas.

Uma aplicação web para administrar seus perfis, com suas demandas, podendo agenda-las, definir prazos, prioridades e status de cada demanda criada.

Cada perfil possui suas demanadas, dessa forma é possivel ter demandas de casa, trabalho, problemas pessoais para resolver, lazeres e entre outros.

Tecnologias utilizadas:
Java spring Boot, framwork bootstrap para interface, Banco de dados PostgreSQL com JPA persistence.
